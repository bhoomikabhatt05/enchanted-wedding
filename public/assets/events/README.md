# Event Photos

Drop final JPGs here (also copy to `src/assets/images/events/`).

Supported:
- `ceremony` / `event-ceremony`
- `reception` / `event-reception`
- `dinner` / `event-dinner`
- `after-party` / `afterParty` / `event-after-party`
- `venue` / `event-venue` / `estate`

Framed via `StoryImage` (wide/square), sepia treatment neutralizes before reveal.
